## Turtle Race Game 🐢🏁

A fun and interactive Turtle Race Game built using Python’s Turtle graphics module. Players place a bet on a turtle color and watch the turtles race across the screen. The game uses random movement to create unpredictable and exciting race outcomes.



## Features
Multiple racing turtles with different colors
User betting system
Random turtle movement
Interactive gameplay
Simple and beginner-friendly Python project



## Technologies Used
Python 3
turtle module
random module



## How to Play
Run the program.
Enter the color of the turtle you think will win.
Watch the race begin.
The game announces whether you won or lost.
Turtle Colors
Red
Yellow
Purple
Green
Blue
Orange



## How to Run
Install Python on your system.
Save the code as main.py



##Run the program:
python main.py

## Game Logic
Each turtle moves forward by a random distance.
The first turtle to cross the finish line wins.
The program compares the winning turtle with the user’s bet.
The result is displayed in the console.
